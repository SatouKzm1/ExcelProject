## 🛠️ Detailed Project Breakdown

### 1. 📊 Pivot Tables in Excel (`Pivot Tables in Excel.xlsx`)
* **Objective:** Summarize over 113,000 global sales transaction records across multiple countries and demographic groups[cite: 1].
* **Key Focus:** Built multi-field Pivot Tables aggregating total **Revenue** ($85.27M), **Cost** ($53.05M), and **Profit** ($32.22M), alongside multi-year country trend matrices (2011–2016) filtered by gender slicers[cite: 1].

### 2. 🧮 Formulas in Excel (`Formulas in Excel.xlsx`)
* **Objective:** Master essential business logic and mathematical operations across 11 dedicated practice worksheets[cite: 1].
* **Key Focus:** Implemented conditional aggregations (`SUMIFS`, `COUNTIFS`), dynamic logic (`IF`, `IFS`), text extractions (`LEFT`, `RIGHT`, `LEN`, `TRIM`, `CONCATENATE`), and working-day date tenure calculations (`DAYS`, `NETWORKDAYS`)[cite: 1].

### 3. 🔍 XLOOKUP in Excel (`XLOOKUP in Excel.xlsx`)
* **Objective:** Perform flexible multi-column data lookups and dataset enrichment without layout limitations[cite: 1].
* **Key Focus:** Utilized `XLOOKUP` for exact match retrievals, dynamic left-side lookups, multi-criteria matching, approximate range lookups, and error fallback handling (replacing legacy `VLOOKUP`/`INDEX+MATCH`)[cite: 1].

### 4. 🎨 Conditional Formatting in Excel (`Conditional Formatting in Excel.xlsx`)
* **Objective:** Apply visual cues and automated formatting to quickly identify key data insights, anomalies, and thresholds[cite: 1].
* **Key Focus:** Built 3-color heatmap gradient scales across monthly product sales ($24–$750), embedded performance data bars, and configured rule-based threshold highlighting for salary levels and duplicate entries[cite: 1].

### 5. 📈 Charts in Excel (`Charts in Excel.xlsx`)
* **Objective:** Translate raw tabular data into intuitive visual business presentations and trend analysis[cite: 1].
* **Key Focus:** Constructed formatted Bar/Column Charts, multi-series Line Trends, Donut Distribution Charts, and Dual-Axis Combo Charts with clean titles, legends, data labels, and color palettes[cite: 1].

### 6. 🧹 Cleaning Data in Excel (`Cleaning Data in Excel.xlsx`)
* **Objective:** Clean and standardize unformatted, messy source data to ensure analytical accuracy[cite: 1].
* **Key Focus:** Executed an end-to-end data preparation workflow using `TRIM`, `CLEAN`, and `PROPER` functions, splitting combined text via Text-to-Columns, eliminating duplicate rows, and standardizing date formats[cite: 1].

### 7. 🚀 Full Project in Excel: Executive Sales Dashboard (`Full Project in Excel.xlsx`)
* **Objective:** Build a comprehensive, end-to-end interactive Business Intelligence Dashboard for executive decision-making[cite: 1].
* **Key Focus:** Integrates data modeling, custom KPI metric cards (Total Sales, Total Profit, Profit Margin, Order Count), interactive Slicer navigation, and interlinked Pivot Charts for seamless real-time data exploration[cite: 1].
